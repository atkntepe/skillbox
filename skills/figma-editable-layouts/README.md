# figma-editable-layouts

Guidance for creating Figma design-mode artifacts that stay editable, designer-friendly, auto-layout based, and easy to adjust later.

## Use this skill when

- Creating Figma screens, UI mockups, dialogs, panels, dashboards, or app pages
- Updating or converting Figma layouts that should remain editable
- Building Figma components, variants, or design-system pieces
- Reviewing Figma work for layer hierarchy, auto layout, text editability, resizing, or designer handoff quality
- Avoiding static screenshot-style output in Figma

## Avoid using this skill when

- The user explicitly wants a flat visual mockup or raster image
- The work is only a diagram, FigJam board, or slide deck with no editable UI layout requirements
- The task does not involve Figma

mkdir -p "$HOME/.agents/skills"
cp -R skills/figma-editable-layouts "$HOME/.agents/skills/figma-editable-layouts"
