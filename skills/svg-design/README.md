# svg-design

Guidance and lightweight tooling for creating, converting, and debugging SVG mockups, illustrations, UI compositions, logos, and diagrams.

## Use this skill when

- Creating a new SVG from a design brief
- Turning CSS, HTML, or screenshot mockups into SVG
- Debugging SVG overlap, clipping, viewBox, scaling, or text wrapping issues
- Reviewing inline SVG in frontend code
- Making SVG output more editable and maintainable

## Avoid using this skill when

- The user wants a raster image, photo edit, or bitmap illustration
- The task is general frontend layout with no SVG deliverable
- The SVG is only a tiny library icon and does not need custom design or debugging

## Install

```sh
mkdir -p "$HOME/.agents/skills"
cp -R skills/svg-design "$HOME/.agents/skills/svg-design"
```
