# Frontend Design Checklist

Use this checklist when creating or reviewing UI.

## Layout

- Clear page structure
- Strong visual hierarchy
- Consistent spacing rhythm
- Responsive behavior for narrow and wide screens
- Avoids unnecessary clutter

## Components

- Clear default, hover, active, focus, disabled, loading, and error states
- Components feel reusable rather than one-off
- Props and naming are expressive
- Variants are intentional and limited

## Visual Design

- Typography scale is deliberate
- Color use supports meaning
- Empty states are designed
- Loading states are graceful
- Important actions are visually prioritized

## Accessibility

- Keyboard navigation works
- Focus states are visible
- Text contrast is sufficient
- Form fields have clear labels
- Interactive elements use semantic HTML where possible

## Implementation

- Minimal dependencies
- Clean component boundaries
- No hardcoded magic values unless justified
- No over-engineering
- Easy to maintain
