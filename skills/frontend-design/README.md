# frontend-design

Frontend UI design and implementation guidance for agentic coding workflows.

## Use this skill when

- Creating a new UI from scratch
- Improving an existing frontend screen
- Reviewing visual hierarchy, spacing, states, responsiveness, or accessibility
- Turning rough UI into production-ready UI
- Making frontend output feel more polished and intentional

## Avoid using this skill when

- The task is backend-only
- The task is purely infrastructure-related
- The user only wants a data model, API route, or database migration

## Install

```sh
mkdir -p "$HOME/.agents/skills"
cp -R skills/frontend-design "$HOME/.agents/skills/frontend-design"
```

For project-local usage:

```sh
mkdir -p .agents/skills
cp -R skills/frontend-design .agents/skills/frontend-design
```
